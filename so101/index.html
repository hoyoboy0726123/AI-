    A-03

    選線材，先印量規確認尺寸

    馬達要剛好塞進列印件，螺絲要剛好鎖得進孔，印表機尺寸偏差一點就會太鬆或塞不進去。所以先選對線材，再花幾分鐘印量規。

    線材建議原因
    PLA+首選，官方指定收縮最小、尺寸最準、最好印。官方 README 和代印說明都指定 PLA+，量規和零件的鬆緊也是照它設計的。
    PETG可以，第二選擇比較韌、比較耐熱，螺絲直接鎖進塑膠時比較不會裂。缺點是容易牽絲，孔和凹槽常常偏緊，一定要用它重印量規確認。
    ABS、ASA新手不建議收縮大、容易翹邊，要有密閉的印表機。馬達凹槽和孔位最容易跑掉。
    碳纖 PLA、碳纖 PETG進階選項尺寸很穩、很硬，但會磨損噴嘴，要換硬化鋼噴嘴。
    絲綢 PLA、木質、TPU不要用絲綢 PLA 層與層之間比較弱，容易斷；TPU 太軟，撐不住手臂。
    光固化樹脂不建議整隻手臂都用零件會變成實心、重一倍，一般樹脂又脆。可以只用來印小零件，細節看下方「用光固化可以嗎」。
    用光固化可以嗎

    可以印，但官方的零件是照 FDM 熱熔列印設計的，光固化有四個要先知道的差別：

    • 重量變兩倍。光固化零件是實心的。本手冊用官方檔案算出：執行臂全部零件實心約 571 cm³，樹脂大約 660 g；PLA+ 照官方 15% 填充只要大約 280 到 360 g。肩膀以外會動的部分，光上臂和前臂兩件樹脂就約 240 g。肩部馬達的負擔會明顯變大。
    • 主控臂最不適合。主控臂樹脂實心約 710 g。主控臂要用手推得動、放手又要撐得住，用的是比較小力的 1/147、1/191 馬達，變重之後很容易自己往下掉。
    • 一般樹脂太脆。M2 螺絲直接鎖進 1.6 mm 導孔時，一般樹脂很容易裂。要用 ABS-like 或高韌性樹脂。熱熔螺母不能用，樹脂加熱不會軟化。
    • 長零件會翹。上臂 142 mm、前臂 131 mm 這種長條零件，後固化時容易彎。照光要均勻，不要照過頭。

    只有光固化機的話，照這樣做：

    1. 用 ABS-like 或高韌性樹脂，不要用一般樹脂。買之前看規格表的熱變形溫度，至少要和 PLA 差不多，馬達運轉時會發熱。
    2. 先做曝光測試，再印 Gauge_0 試塞馬達。曝光過度會讓孔變小、零件變胖。
    3. 零件不要挖空。螺絲孔周圍需要實心材料才鎖得住。
    4. 官方整盤檔的擺放方向是給 FDM 用的。光固化要重新斜擺，支撐不要長在馬達凹槽、舵盤接觸面和螺絲孔上。
    5. M2 的 1.6 mm 導孔，先用 M2 手攻牙攻出螺紋，再鎖螺絲，比較不會裂。
    6. 洗乾淨再照光固化。全程戴手套，保持通風，未固化的樹脂和清洗液不能倒進水槽。
    7. 兩隻手臂實心加上支撐，準備至少 1.5 公斤樹脂。

    本手冊建議的做法：手臂主體用 PLA+ 熱熔列印；光固化拿來印小而要求精度的零件，例如階段 B 的推頭 probe_tip。

    官方只指定 PLA+，沒有提到光固化。這一段是本手冊依官方零件尺寸和材料特性整理的建議。

    同一捲線材印到底

    不同品牌、甚至同品牌不同顏色，收縮都會有一點差異。量規用哪一捲印，整隻手臂就用同一捲印。中途換線材，就重印量規再確認一次。線材受潮會讓尺寸變胖、牽絲變多，開封久的線材先烘乾。

    官方設計的孔有多大。本手冊直接量了官方 STEP 設計檔，手臂上和螺絲有關的孔是這幾種：

    設計直徑用途印出來太緊怎麼辦
    3.2 mmM3 螺絲穿過去的孔，手臂零件鎖到舵盤上用用 3.2 mm 鑽頭，手拿著慢慢轉，把孔清乾淨
    5.4 到 6.0 mmM3 螺絲頭沉進去的凹孔螺絲頭要能整個沉進去，卡住的話一樣用鑽頭清

    1. 依照官方建議設定切片：PLA+、0.4 mm 噴嘴配 0.2 mm 層高，或 0.6 mm 噴嘴配 0.4 mm 層高、填充 15%。

    3. 先做一次流量校正，也叫擠出倍率。擠出太多，是孔和凹槽變緊最常見的原因。
    4. 第一層開「象腳補償」0.1 到 0.15 mm，貼著平台那一面的凹槽才不會變小。

    6. 印 Gauge_0，拿馬達去試塞。官方的判斷標準請看 官方示範影片。
    7. 太緊或太鬆，就調整印表機設定再印一次。調好之前不要印整盤零件。
    8. 流量校正過還是太緊，就把切片軟體的孔洞補償加 0.05 到 0.1 mm：Bambu Studio 和 OrcaSlicer 叫 X-Y hole compensation，Cura 叫 Hole Horizontal Expansion。太鬆就往負的調。一次只調 0.05 mm。
    A-04

    印整盤執行臂零件，拆支撐

    1. 打開 A-02 下載的整盤檔案，用 A-03 調好的設定切片。
    2. 支撐設定為「全部區域」，但與水平面夾角大於 45° 的斜面不需要支撐。
    3. 確認水平方向的螺絲孔裡面沒有長支撐，有的話在切片軟體裡把那裡的支撐去掉。
    4. 印完用刮刀把零件從平台鏟下來，把所有支撐材料拆乾淨，特別是馬達要塞進去的凹槽。
    5. 組裝前先試孔。拿一顆 M3 × 6 試穿每個 3.2 mm 的孔，要能順順穿過。水平方向的孔頂端常會稍微下垂變小，用 3.2 mm 鑽頭手轉清一下就好。
    6. 拿一顆馬達試塞每個馬達凹槽，用手壓得進去、不會晃就對了。太緊不要硬塞，用砂紙或銼刀修凹槽的內壁。

    M2 螺絲鎖進塑膠時

    鎖到零件貼平，再輕輕多轉一點點就停。PLA 鎖太緊會裂開或滑牙。萬一滑牙，可以換長一點的 M2 × 8 再鎖一次。

    第一次用 Python 控制手臂

    這段程式由本手冊撰寫，用的類別名稱、方法和參數都已經對照 LeRobot 0.6.2 原始碼確認。它會讀出每個關節的角度，再讓夾爪慢慢開合一次。

    執行前先擺好手臂

    程式結束時會自動放掉馬達出力，手臂會變軟。如果手臂舉在空中，會直接掉下來。執行前請把手臂收折在桌面上，旁邊不要放東西。

    first_move.py
    import time
from lerobot.robots.so_follower import SO101Follower, SO101FollowerConfig

config = SO101FollowerConfig(
    port="COM3",                   # 換成 A-06 找到的連接埠
    id="my_awesome_follower_arm",  # 和 A-16 校準時用同一個名字
    max_relative_target=5.0,       # 每次最多動 5，一定要寫成小數
)
robot = SO101Follower(config)
robot.connect()
try:
    obs = robot.get_observation()
    for name, value in obs.items():
        print(name, round(value, 1))
    action = {k: v for k, v in obs.items() if k.endswith(".pos")}
    for target in (50.0, 20.0):    # 夾爪 0 到 100，先到 50 再到 20
        action["gripper.pos"] = target
        for _ in range(20):
            robot.send_action(action)
            time.sleep(0.05)
    print("負載讀數:", robot.bus.sync_read("Present_Load"))
finally:
    robot.disconnect()
    • 關節 1 到 5 的單位是「度」，0 度是校準時記錄範圍的正中間；夾爪是 0 到 100。
    • max_relative_target 必須寫成 5.0，寫成整數 5 程式會報錯。
    • 最後印出的負載讀數是馬達的原始數值，官方沒有說明單位，只能拿來比較大小。

    孔中心到荷重元端面的距離3.5 mm只有一個第三方模型，要量

    下載套件裡的 cad/probe_tool.scad 用免費的 OpenSCAD 打開，最上面有 hole_from_end、cell_head_len、hole_pitch、clamp_w 等參數。改成你量到的數字，存檔後依序匯出 part="block" 和 part="tip" 兩個 STL。

    1. 列印。PLA 或 PETG，層高 0.2 mm，牆 4 圈，填充 40% 以上。檔案已經擺好方向：治具座的三根小柱子朝上，推頭的尖端朝上。
    2. 試孔。拿一顆 M3 螺絲穿過治具上的 4 個孔，要能順順穿過。太緊就用 3.4 mm 鑽頭手轉擴孔。
    3. 分清荷重元的兩端。有線的那一端是固定端，孔是 M3 螺紋；沒有線的那一端是受力端，孔是光孔。
    1. 鎖固定端。把荷重元有線的那一端貼在治具座伸出來的舌片上，2 顆 M3 × 10 從舌片那一側穿過去，直接鎖進荷重元的螺紋孔。鎖緊即可，不要用力到滑牙。
    2. 鎖推頭。推頭的平板貼在荷重元受力端的另一面，也就是和舌片相反的那一面，尖端朝外。2 顆 M3 × 12 穿過平板和荷重元，另一側用螺帽鎖緊。
    3. 整理細線。治具座側面有 3 根交錯的小柱子，4 條細線在柱子之間繞 S 形穿過，再用小束帶穿過旁邊的橋形扣固定。這樣拉到線時，力量不會傳到荷重元的出線口。
    4. 確認中間懸空。荷重元中間那段，四周都不能碰到治具。拿一張紙從荷重元中段和舌片之間穿過去，要能順利通過。
    細線很脆弱

    荷重元的線大約只有 0.6 mm 粗，最容易從出線口斷掉，斷了幾乎修不好，只能換一顆。不要用線把荷重元提起來，也不要反覆彎折出線口。

    接線：荷重元 → HX711 → Arduino Nano

    第一段：荷重元的 4 條線接到 HX711。SparkFun 紅色板上印的是線的顏色，通用綠色板印的是訊號名稱。

    荷重元的線訊號SparkFun 板通用綠色板
    紅激勵 正REDE+
    黑激勵 負BLKE−
    白訊號 負WHTA−
    綠訊號 正GRNA+
    沒有線YLW 空著B+、B− 空著

    第二段：HX711 接到 Nano。

    SparkFun 板通用綠色板接到 Arduino Nano
    VCCVCC5V
    VDD沒有這個腳5V，和 VCC 接同一個腳
    DATDTD2
    CLKSCKD3
    GNDGNDGND
    SparkFun 板的 VDD 一定要接

    VCC 供電給荷重元，VDD 決定數位訊號的電壓。VDD 沒接的話，Nano 一個數字都讀不到。

    不要照 SparkFun 範例的腳位

    SparkFun 自己的範例程式是 DAT 接 3、CLK 接 2，剛好和本手冊相反。本手冊的韌體固定用 DAT 接 D2、CLK 接 D3。

    1. 荷重元的細線焊在排針上，每個焊點套熱縮管。不要用螺絲端子夾這麼細的線。
    2. HX711 用雙面膠或束帶固定在手腕或前臂上，越靠近荷重元越好。荷重元的線只有 110 mm 長，而且這段線越短雜訊越小。
    3. HX711 到 Nano 的 4 條線沿著手臂走到底座，經過手腕的兩個關節時各留一段鬆弛的線圈，讓關節轉動時不會拉扯。線長盡量在 1 公尺以內。
    4. 訊號線遠離馬達的電源線。Nano 用自己的 USB 線直接接電腦，不要和馬達驅動板共用同一個 USB 集線器。
    用三用電錶先檢查荷重元

    荷重元先不要接到 HX711，量電阻：紅、黑之間大約 1090 Ω，綠、白之間大約 1000 Ω。顯示 OL 代表有線斷了。

    SparkFun 板的腳位對照，是直接讀 SparkFun 官方 GitHub 上的電路板檔案確認的。少數商店標示的綠、白兩線顏色相反，沒關係，B-05 的校正會自動處理正負號。

    so101_force.ino
    /*
 * so101_force.ino  --  TAL221 mini load cell + HX711 + Arduino Nano
 * Force probe firmware for the SO-101 (LeRobot) thumbstick-pushing jig.
 *
 * Library : "HX711 Arduino Library" by Bogdan Necula (github.com/bogde/HX711),
 *           tested with release 0.7.5.  NOTE: in the Arduino Library Manager
 *           there is ALSO a library simply called "HX711" by Rob Tillaart -
 *           that is a DIFFERENT library and this sketch will not build with it.
 *           arduino-cli:  arduino-cli lib install "HX711 Arduino Library"
 * Board   : Arduino Nano (ATmega328P)  FQBN arduino:avr:nano
 *           (clones with the old bootloader: arduino:avr:nano:cpu=atmega328old)
 *
 * Wiring (HX711 board -> Nano):
 *   DAT / DT / DOUT -> D2      CLK / SCK / PD_SCK -> D3
 *   VCC (and VDD on SparkFun board) -> 5V        GND -> GND
 *
 * Serial: 115200 baud, lines end with "\r\n".
 *   Data line   : F,<millis>,<grams>        e.g.  F,123456,12.34
 *                 (grams = "nan" until a calibration is stored)
 *   Reply lines : OK,...  /  ERR,...  /  R,...
 *   Info lines  : start with '#'  (PC software should ignore them)
 *
 * Commands (type in Serial Monitor, newline at the end):
 *   t          tare: set zero (NOTHING may touch the probe tip)
 *   c<grams>   calibrate with a known weight resting on the tip, e.g. c100
 *              (do 't' first with no weight). Scale factor is saved to EEPROM.
 *   r          print one raw reading:  R,<millis>,<raw_avg>,<offset>,<counts_per_gram>
 *   a<n>       moving-average window, n = 1..16 (default 4, not saved)
 *   ?          help + current settings
 *
 * Sign convention: calibrate with the weight pressing the tip the SAME way the
 * thumbstick will press back on it. Then pushing = positive grams.
 */

#include <EEPROM.h>
#include <math.h>
#include <stdlib.h>
#include "HX711.h"

// ---------------- user settings ----------------
const uint8_t  PIN_DOUT        = 2;      // HX711 DAT/DT/DOUT
const uint8_t  PIN_SCK         = 3;      // HX711 CLK/SCK
const long     BAUD            = 115200;
const uint8_t  DEFAULT_WINDOW  = 4;      // samples in moving average
const uint8_t  MAX_WINDOW      = 16;
const uint8_t  TARE_SAMPLES    = 16;     // samples averaged for t and c
const uint16_t READY_TIMEOUT_MS = 600;   // 10 SPS -> 100 ms per sample
const float    MIN_COUNTS_PER_G = 50.0;  // below this, calibration is rejected

// ---------------- EEPROM layout ----------------
const int      EE_ADDR  = 0;
const uint32_t EE_MAGIC = 0x464F5231UL;  // "FOR1"
struct CalData {
  uint32_t magic;
  float    countsPerGram;
  uint32_t check;      // magic XOR raw bits of countsPerGram
};

HX711 scale;

float   countsPerGram = NAN;   // NAN = not calibrated
long    offsetRaw     = 0;
long    ring[MAX_WINDOW];
uint8_t window        = DEFAULT_WINDOW;
uint8_t ringCount     = 0;
uint8_t ringPos       = 0;
unsigned long lastSampleMs = 0;
unsigned long lastWarnMs   = 0;

char    cmdBuf[24];
uint8_t cmdLen = 0;

// ------------------------------------------------
static uint32_t floatBits(float f) {
  uint32_t u;
  memcpy(&u, &f, sizeof(u));
  return u;
}

static bool loadCalibration() {
  CalData d;
  EEPROM.get(EE_ADDR, d);
  if (d.magic != EE_MAGIC) return false;
  if (d.check != (d.magic ^ floatBits(d.countsPerGram))) return false;
  if (isnan(d.countsPerGram) || isinf(d.countsPerGram)) return false;
  if (fabs(d.countsPerGram) < MIN_COUNTS_PER_G) return false;
  countsPerGram = d.countsPerGram;
  return true;
}

static void saveCalibration(float cpg) {
  CalData d;
  d.magic = EE_MAGIC;
  d.countsPerGram = cpg;
  d.check = d.magic ^ floatBits(cpg);
  EEPROM.put(EE_ADDR, d);   // put() only rewrites bytes that changed
}

// Read one raw sample, waiting at most READY_TIMEOUT_MS. Returns false on timeout.
static bool readRaw(long &out) {
  if (!scale.wait_ready_timeout(READY_TIMEOUT_MS, 1)) return false;
  out = scale.read();
  lastSampleMs = millis();   // keeps loop() from warning after a long t / c / r
  return true;
}

// Average n raw samples (blocking, with timeout). Returns false on timeout.
static bool readRawAverage(uint8_t n, long &out) {
  long long sum = 0;
  for (uint8_t i = 0; i < n; i++) {
    long v;
    if (!readRaw(v)) return false;
    sum += v;
  }
  out = (long)(sum / n);
  return true;
}

static void resetRing() {
  ringCount = 0;
  ringPos = 0;
}

static void pushRing(long v) {
  ring[ringPos] = v;
  ringPos = (ringPos + 1) % window;
  if (ringCount < window) ringCount++;
}

static long ringAverage() {
  long long sum = 0;
  for (uint8_t i = 0; i < ringCount; i++) sum += ring[i];
  return ringCount ? (long)(sum / ringCount) : 0;
}

static void printHelp() {
  Serial.println(F("# so101_force  commands: t=tare  c<grams>=calibrate  r=raw  a<n>=avg window  ?=help"));
  Serial.print(F("# counts_per_gram="));
  if (isnan(countsPerGram)) Serial.println(F("NOT_CALIBRATED"));
  else Serial.println(countsPerGram, 3);
  Serial.print(F("# offset_raw="));
  Serial.print(offsetRaw);
  Serial.print(F(" window="));
  Serial.println(window);
}

static void doTare() {
  long avg;
  if (!readRawAverage(TARE_SAMPLES, avg)) {
    Serial.println(F("ERR,TARE,HX711_NOT_READY"));
    return;
  }
  offsetRaw = avg;
  resetRing();
  Serial.print(F("OK,TARE,"));
  Serial.println(offsetRaw);
}

static void doCalibrate(const char *arg) {
  float grams = atof(arg);
  if (!(grams > 0.0f)) {
    Serial.println(F("ERR,CAL,USAGE: c<grams>  e.g. c100"));
    return;
  }
  long avg;
  if (!readRawAverage(TARE_SAMPLES, avg)) {
    Serial.println(F("ERR,CAL,HX711_NOT_READY"));
    return;
  }
  float cpg = (float)(avg - offsetRaw) / grams;
  if (fabs(cpg) < MIN_COUNTS_PER_G) {
    Serial.print(F("ERR,CAL,SIGNAL_TOO_SMALL,"));
    Serial.println(cpg, 3);
    Serial.println(F("# Did you tare (t) with no weight first? Is the weight on the TIP? Check wiring."));
    return;
  }
  countsPerGram = cpg;
  saveCalibration(cpg);
  resetRing();
  Serial.print(F("OK,CAL,"));
  Serial.println(countsPerGram, 3);
}

static void doRaw() {
  long avg;
  if (!readRawAverage(window, avg)) {
    Serial.println(F("ERR,RAW,HX711_NOT_READY"));
    return;
  }
  Serial.print(F("R,"));
  Serial.print(millis());
  Serial.print(',');
  Serial.print(avg);
  Serial.print(',');
  Serial.print(offsetRaw);
  Serial.print(',');
  if (isnan(countsPerGram)) Serial.println(F("nan"));
  else Serial.println(countsPerGram, 3);
}

static void handleCommand(char *s) {
  while (*s == ' ') s++;
  if (*s == '\0') return;
  char c = *s;
  if (c >= 'A' && c <= 'Z') c = c - 'A' + 'a';
  char *arg = s + 1;
  while (*arg == ' ') arg++;
  switch (c) {
    case 't': doTare(); break;
    case 'c': doCalibrate(arg); break;
    case 'r': doRaw(); break;
    case 'a': {
      int n = atoi(arg);
      if (n < 1 || n > MAX_WINDOW) {
        Serial.println(F("ERR,AVG,RANGE_1_16"));
      } else {
        window = (uint8_t)n;
        resetRing();
        Serial.print(F("OK,AVG,"));
        Serial.println(window);
      }
      break;
    }
    case '?': case 'h': printHelp(); break;
    default:
      Serial.print(F("ERR,UNKNOWN,"));
      Serial.println(s);
  }
}

static void pollSerial() {
  while (Serial.available() > 0) {
    char ch = (char)Serial.read();
    if (ch == '\n' || ch == '\r') {
      cmdBuf[cmdLen] = '\0';
      handleCommand(cmdBuf);
      cmdLen = 0;
    } else if (cmdLen < sizeof(cmdBuf) - 1) {
      cmdBuf[cmdLen++] = ch;
    }
  }
}

void setup() {
  Serial.begin(BAUD);
  scale.begin(PIN_DOUT, PIN_SCK);      // channel A, gain 128
  // Library 0.7.5 leaves DOUT as plain INPUT on AVR; a pull-up makes a
  // disconnected HX711 read as "not ready" instead of random numbers.
  pinMode(PIN_DOUT, INPUT_PULLUP);

  Serial.println(F("# so101_force v1.0 (TAL221 + HX711, DOUT=D2 SCK=D3)"));
  if (loadCalibration()) {
    Serial.print(F("# calibration loaded from EEPROM, counts_per_gram="));
    Serial.println(countsPerGram, 3);
  } else {
    Serial.println(F("# NOT CALIBRATED: send t (no load), put a known weight on the tip, send c<grams>"));
  }
  delay(400);                          // let HX711 settle after power-up
  Serial.println(F("# auto-tare at boot: do not touch the probe"));
  doTare();
  lastSampleMs = millis();
}

void loop() {
  pollSerial();

  if (scale.is_ready()) {
    long v = scale.read();
    lastSampleMs = millis();
    if (v >= 8388607L || v <= -8388608L) {
      // ADC at full scale: open/broken wire or huge overload
      if (millis() - lastWarnMs > 1000) {
        Serial.println(F("# WARN,ADC_SATURATED (check load-cell wires)"));
        lastWarnMs = millis();
      }
    }
    pushRing(v);
    float grams = (float)(ringAverage() - offsetRaw) / countsPerGram;  // NAN if not calibrated
    Serial.print(F("F,"));
    Serial.print(lastSampleMs);
    Serial.print(',');
    if (isnan(grams)) Serial.println(F("nan"));
    else Serial.println(grams, 2);
  } else if (millis() - lastSampleMs > READY_TIMEOUT_MS && millis() - lastWarnMs > 1000) {
    Serial.println(F("# WARN,HX711_NOT_READY (check DAT->D2, CLK->D3, VCC, GND)"));
    lastWarnMs = millis();
  }
}

    B-05

    用砝碼校正

    1. 先暖機 10 分鐘。Nano 插上 USB 放著。HX711 和荷重元剛通電時會慢慢升溫，零點會漂。
    2. 把治具座固定在桌上，推頭尖端朝正上方。治具座側躺，用小虎鉗、夾子或膠帶固定。這時候荷重元是水平的，中間懸空。砝碼放在推頭上，壓的方向就和之後蘑菇頭頂回來的方向一樣，推力讀數才會是正的。
    3. 想放紙杯當托盤，就現在放。用膠帶把小紙杯貼在推頭上，放砝碼比較穩。之後的歸零會把紙杯一起扣掉。
    4. 歸零。推頭上不放砝碼，在監控視窗輸入 t，等出現 OK,TARE, 開頭的回覆。
    5. 校正。輕輕放上 100 g 砝碼，等 3 秒，輸入 c100。用 200 g 就輸入 c200。
    6. 看回覆。應該出現 OK,CAL, 後面接一個數字，500 g 荷重元大約在 2360 到 3650 之間。差很多就是砝碼克數打錯、荷重元不是 500 g，或線接錯。
    7. 拿掉砝碼。讀數要回到 0，誤差在正負 0.3 g 以內。回不去就重新做第 4 到第 6 步。

    線性檢查。先輸入 t 歸零，再依序放 1、10、50、100、200 g，每次等 3 秒，看 10 筆左右的平均，填進下表。每拿掉一個砝碼，都要確認讀數回到 0 再放下一個。

    砝碼讀數誤差 = 讀數 − 砝碼建議的合格範圍
    1 g±0.5 g
    10 g±0.5 g
    50 g±0.5 g
    100 g±1 g
    200 g±2 g

    #!/usr/bin/env python3
"""
force_probe.py - PC side of the SO-101 force probe (TAL221 + HX711 + Arduino Nano).

The Nano (firmware so101_force.ino) streams lines at 115200 baud:
    F,<millis>,<grams>      force sample ("nan" until calibrated)
    OK,... / ERR,... / R,... replies to commands
    # ...                    info lines
Commands sent to the Nano: t (tare), c<grams> (calibrate), r (raw), a<n> (avg window).

Requirements: Python >= 3.10, pyserial  (pip install pyserial)
The "push" example additionally needs LeRobot installed and a calibrated SO-101 follower.

Examples
    python force_probe.py monitor --port /dev/ttyUSB0
    python force_probe.py tare    --port /dev/ttyUSB0
    python force_probe.py cal 100 --port /dev/ttyUSB0          # 100 g weight resting on the tip
    python force_probe.py raw     --port /dev/ttyUSB0
    python force_probe.py push --port /dev/ttyUSB0 --robot-port /dev/ttyACM0 \\
        --robot-id my_awesome_follower_arm --joint wrist_flex --direction 1 --target 50 --limit 300

Safety (push): stops at --target, backs off immediately at --limit, stops if the sensor goes
silent, reads a negative force, or the joint travelled --max-travel degrees. First Ctrl+C =
controlled stop and retreat to the start pose; second Ctrl+C = emergency: torque OFF (arm goes limp!).
"""

BAUD = 115200


@dataclass(frozen=True)
class Sample:
    seq: int          # running sample counter (PC side)
    t_host: float     # time.monotonic() when the line arrived
    millis: int       # Nano millis()
    grams: float      # nan if the Nano is not calibrated


class ForceProbe:
    """Reads the Nano CSV stream in a background thread."""

    def __init__(self, port: str, baud: int = BAUD, boot_timeout: float = 4.0, verbose: bool = False):
        # Opening the port resets a Nano (DTR). The firmware then prints a banner and auto-tares.
        self.ser = serial.Serial(port, baud, timeout=0.1)
        self.verbose = verbose
        self._latest: Sample | None = None
        self._seq = 0
        self._cv = threading.Condition()
        self._replies: queue.Queue[str] = queue.Queue()
        self._stop = threading.Event()
        self._thread = threading.Thread(target=self._reader, daemon=True)
        self._thread.start()
        if self.wait_new(-1, boot_timeout) is None:
            self.close()
            raise RuntimeError(f"No 'F,' data from {port} within {boot_timeout:.0f} s. "
                               "Wrong port? Firmware not uploaded? Baud must be 115200.")

    # ---------- reading ----------
    def _reader(self) -> None:
        while not self._stop.is_set():
            try:
                raw = self.ser.readline()
            except (serial.SerialException, OSError) as e:
                print(f"[force] serial error: {e}", file=sys.stderr)
                break
            if not raw:
                continue
            line = raw.decode("ascii", errors="replace").strip()
            if line.startswith("F,"):
                parts = line.split(",")
                if len(parts) != 3:
                    continue
                try:
                    millis, grams = int(parts[1]), float(parts[2])
                except ValueError:
                    continue  # partial line right after reset
                with self._cv:
                    self._seq += 1
                    self._latest = Sample(self._seq, time.monotonic(), millis, grams)
                    self._cv.notify_all()
            elif line.startswith(("OK,", "ERR,", "R,")):
                self._replies.put(line)
            elif line.startswith("#"):
                if self.verbose or "WARN" in line or "NOT CALIBRATED" in line:
                    print(f"[force] {line}")

    def latest(self) -> Sample | None:
        with self._cv:
            return self._latest

    def wait_new(self, after_seq: int, timeout: float) -> Sample | None:
        """Block until a sample with seq > after_seq arrives (or timeout)."""
        deadline = time.monotonic() + timeout
        with self._cv:
            while self._latest is None or self._latest.seq <= after_seq:
                left = deadline - time.monotonic()
                if left <= 0:
                    return None
                self._cv.wait(left)
            return self._latest

    # ---------- commands ----------
    def command(self, cmd: str, timeout: float = 6.0) -> str:
        while not self._replies.empty():
            self._replies.get_nowait()
        self.ser.write((cmd + "\n").encode("ascii"))
        self.ser.flush()
        try:
            reply = self._replies.get(timeout=timeout)
        except queue.Empty:
            raise RuntimeError(f"no reply to '{cmd}'") from None
        if reply.startswith("ERR"):
            raise RuntimeError(f"Nano replied {reply}")
        return reply

    def tare(self) -> str:
        return self.command("t")

    def calibrate(self, grams: float) -> str:
        return self.command(f"c{grams:g}")

    def raw(self) -> str:
        return self.command("r")

    def set_window(self, n: int) -> str:
        return self.command(f"a{int(n)}")

    def close(self) -> None:
        self._stop.set()
        self._thread.join(timeout=1.0)
        try:
            self.ser.close()
        except Exception:
            pass

def import_so101():
    """LeRobot >= 0.4: lerobot.robots.so_follower ; LeRobot 0.3.x: lerobot.robots.so101_follower."""
    try:
        from lerobot.robots.so_follower import SO101Follower, SO101FollowerConfig
    except ImportError:
        try:
            from lerobot.robots.so101_follower import SO101Follower, SO101FollowerConfig
        except ImportError:
            sys.exit("LeRobot is not installed in this Python environment (activate the lerobot env).")
    return SO101Follower, SO101FollowerConfig


class StopFlag:
    """1st Ctrl+C -> graceful stop; 2nd Ctrl+C -> KeyboardInterrupt (emergency)."""

    def __init__(self) -> None:
        self.event = threading.Event()
        self._old = signal.signal(signal.SIGINT, self._handler)

    def _handler(self, signum, frame) -> None:
        if self.event.is_set():
            raise KeyboardInterrupt
        print("\n[Ctrl+C] stopping -> retreat to start pose. Press Ctrl+C again for EMERGENCY torque off.")
        self.event.set()

    def restore(self) -> None:
        signal.signal(signal.SIGINT, self._old)


def move_joint_to(robot, goal: dict, key: str, target: float, step: float, period: float) -> None:
    """Ramp one joint to `target` in increments of `step` degrees."""
    while abs(goal[key] - target) > 1e-6:
        delta = target - goal[key]
        goal[key] += max(-step, min(step, delta))
        robot.send_action(dict(goal))
        time.sleep(period)


def push(args) -> int:
    if args.limit > args.capacity:
        sys.exit(f"--limit {args.limit} g is above the load-cell capacity {args.capacity} g. "
                 "For a 100 g TAL221 use e.g. --capacity 100 --limit 100 --target 50.")
    if not 0 < args.target < args.limit:
        sys.exit("need 0 < --target < --limit")
    SO101Follower, SO101FollowerConfig = import_so101()

    probe = stop = robot = None
    goal: dict | None = None
    start: dict = {}
    key = ""
    log_f = open(args.log, "w", newline="") if args.log else None
    log = csv.writer(log_f) if log_f else None
    if log:
        log.writerow(["t_s", "nano_ms", "force_g", "goal_deg", "phase"])
    exit_code = 1
    try:
        probe = ForceProbe(args.port, verbose=args.verbose)
        s = probe.latest()
        if s is None or math.isnan(s.grams):
            raise RuntimeError("Force sensor NOT calibrated. Run:  tare, then  cal <grams>  first.")
        probe.set_window(args.avg)
        input("Make sure NOTHING touches the probe tip, then press ENTER to tare... ")
        print("[force]", probe.tare())
        stop = StopFlag()   # from here on: 1st Ctrl+C = graceful stop, 2nd = emergency torque off

        cfg = SO101FollowerConfig(
            port=args.robot_port,
            id=args.robot_id,
            use_degrees=True,                                # joint values in degrees (all LeRobot versions)
            max_relative_target=float(args.max_rel),         # must be float (LeRobot raises TypeError on int)
            disable_torque_on_disconnect=args.release_torque,
        )
        robot = SO101Follower(cfg)
        robot.connect(calibrate=False)                       # never start the interactive calibration here
        if not robot.is_calibrated:
            raise RuntimeError("SO-101 is not calibrated for id "
                               f"'{args.robot_id}'. Run lerobot-calibrate --robot.type=so101_follower "
                               f"--robot.port={args.robot_port} --robot.id={args.robot_id}")
        obs = robot.get_observation()
        start = {k: float(v) for k, v in obs.items() if k.endswith(".pos")}
        key = f"{args.joint}.pos"
        if key not in start:
            raise RuntimeError(f"unknown joint '{args.joint}'. Valid: {[k[:-4] for k in start]}")
        goal = dict(start)
        if args.gripper_goal is not None and "gripper.pos" in goal:
            goal["gripper.pos"] = float(args.gripper_goal)   # squeeze the block (0..100 scale)
        robot.send_action(dict(goal))    # hold the current pose (connect() does not set goals)
        print(f"start {key} = {start[key]:.2f} deg, gripper.pos = {start.get('gripper.pos', float('nan')):.1f} "
              f"(goal {goal.get('gripper.pos', float('nan')):.1f}); target {args.target} g, hard limit {args.limit} g")

        t0 = time.monotonic()
        reason, reached, emergency = "stopped by user", False, False
        while not stop.event.is_set():
            t_loop = time.monotonic()
            s = probe.latest()
            if s is None or t_loop - s.t_host > args.stale:
                reason = "force sensor silent (cable? Nano reset?)"
                break
            f = s.grams
            if log:
                log.writerow([f"{t_loop - t0:.3f}", s.millis, f"{f:.2f}", f"{goal[key]:.3f}", "push"])
            if math.isnan(f):
                reason = "force is nan (calibration lost?)"
                break
            if f >= args.limit:
                reason, emergency = f"HARD LIMIT: {f:.1f} g >= {args.limit} g", True
                break
            if f <= -args.neg_limit:
                reason = (f"negative force {f:.1f} g: wrong --direction, probe pushed from the wrong side, "
                          "or calibrate again with the weight pressing the tip the pushing way")
                break
            if f >= args.target:
                reason, reached = f"target reached: {f:.1f} g", True
                break
            # big steps in free air, smaller steps once in contact (proportional to remaining force)
            step = args.step if f < args.contact else max(args.min_step, args.step * (args.target - f) / args.target)
            new = goal[key] + args.direction * step
            if abs(new - start[key]) > args.max_travel:
                reason = f"moved {args.max_travel} deg without reaching the target (no contact?)"
                break
            goal[key] = new
            sent = robot.send_action(dict(goal))   # may be clipped by max_relative_target
            goal[key] = float(sent.get(key, new))
            print(f"\r{key}={goal[key]:8.2f} deg  force={f:7.2f} g ", end="", flush=True)
            time.sleep(max(0.0, args.period - (time.monotonic() - t_loop)))
        print(f"\n-> {reason}")

        if emergency:
            goal[key] -= args.direction * args.backoff     # immediate back-off
            robot.send_action(dict(goal))
        elif reached and args.hold > 0:
            t_end = time.monotonic() + args.hold
            while time.monotonic() < t_end and not stop.event.is_set():
                s = probe.latest()
                if s is None or time.monotonic() - s.t_host > args.stale or s.grams >= args.limit:
                    print("hold aborted (limit or sensor silent)")
                    break
                if log:
                    log.writerow([f"{time.monotonic() - t0:.3f}", s.millis, f"{s.grams:.2f}", f"{goal[key]:.3f}", "hold"])
                print(f"\rholding: force={s.grams:7.2f} g ", end="", flush=True)
                time.sleep(args.period)
            print()
        exit_code = 0 if reached else 2
    except KeyboardInterrupt:
        print("\nEMERGENCY: disabling torque (arm will go limp)")
        if robot is not None:
            robot.config.disable_torque_on_disconnect = True
            try:
                robot.disconnect()
            except Exception as e:
                print("disconnect failed:", e)
            robot = None
        exit_code = 3
    except (RuntimeError, serial.SerialException) as e:
        print("ERROR:", e)
    finally:
        if robot is not None and robot.is_connected:
            if goal is not None:
                try:
                    print("retreating to start pose ...")
                    move_joint_to(robot, goal, key, start[key], step=1.0, period=0.05)
                except BaseException as e:  # bus error or 2nd Ctrl+C -> stop pushing at any cost
                    print("retreat failed/aborted:", repr(e), "-> torque OFF (arm goes limp)")
                    robot.config.disable_torque_on_disconnect = True
            try:
                robot.disconnect()
            except Exception as e:
                print("disconnect failed:", e)
        if stop is not None:
            stop.restore()
        if probe is not None:
            probe.close()
        if log_f:
            log_f.close()
    return exit_code

def main(argv: list[str] | None = None) -> int:
    ap = argparse.ArgumentParser(description=__doc__, formatter_class=argparse.RawDescriptionHelpFormatter)
    sub = ap.add_subparsers(dest="cmd", required=True)

    def add_port(p):
        p.add_argument("--port", required=True, help="Nano serial port, e.g. /dev/ttyUSB0 or COM5")
        p.add_argument("--verbose", action="store_true", help="also print '#' info lines")

    p = sub.add_parser("monitor", help="print force values")
    add_port(p)
    p.add_argument("--seconds", type=float, default=0, help="stop after N s (0 = until Ctrl+C)")
    p.add_argument("--csv", help="also save samples to this CSV file")
    add_port(sub.add_parser("tare", help="zero the sensor (nothing on the tip)"))
    p = sub.add_parser("cal", help="calibrate: known weight resting on the tip")
    p.add_argument("grams", type=float)
    add_port(p)
    add_port(sub.add_parser("raw", help="print one raw HX711 reading"))

    p = sub.add_parser("push", help="SO-101 example: move one joint until force reaches target")
    add_port(p)
    p.add_argument("--robot-port", required=True, help="SO-101 follower bus port (lerobot-find-port)")
    p.add_argument("--robot-id", default="my_awesome_follower_arm", help="same id as used for lerobot-calibrate")
    p.add_argument("--joint", default="wrist_flex",
                   choices=["shoulder_pan", "shoulder_lift", "elbow_flex", "wrist_flex", "wrist_roll"])
    p.add_argument("--direction", type=int, choices=[-1, 1], default=1, help="+1 or -1: which way pushes")
    p.add_argument("--target", type=float, default=50.0, help="stop when force >= this (g)")
    p.add_argument("--limit", type=float, default=300.0, help="hard safety limit (g)")
    p.add_argument("--capacity", type=float, default=500.0, help="load-cell capacity (g): 500 or 100")
    p.add_argument("--contact", type=float, default=3.0, help="force (g) that counts as contact")
    p.add_argument("--neg-limit", type=float, default=20.0, help="stop if force <= -this (g)")
    p.add_argument("--step", type=float, default=0.2, help="step in free air (deg)")
    p.add_argument("--min-step", type=float, default=0.03, help="smallest step near target (deg)")
    p.add_argument("--period", type=float, default=0.1, help="control period (s)")
    p.add_argument("--max-travel", type=float, default=15.0, help="max joint travel from start (deg)")
    p.add_argument("--max-rel", type=float, default=5.0, help="LeRobot max_relative_target (deg)")
    p.add_argument("--backoff", type=float, default=3.0, help="immediate back-off at hard limit (deg)")
    p.add_argument("--stale", type=float, default=0.6, help="max age of a force sample (s)")
    p.add_argument("--avg", type=int, default=2, help="firmware moving-average window during push")
    p.add_argument("--hold", type=float, default=2.0, help="hold at target for N s before retreat")
    p.add_argument("--gripper-goal", type=float, default=None,
                   help="gripper goal (0..100) to keep squeezing the probe block; default: hold present value. "
                        "Strap the block to the fingers with a zip tie anyway.")
    p.add_argument("--release-torque", action="store_true",
                   help="disable torque at the end (arm goes limp!) - default keeps holding the start pose")
    p.add_argument("--log", default="push_log.csv", help="CSV log file ('' to disable)")

    args = ap.parse_args(argv)
    if args.cmd == "push":
        return push(args)

    try:
        probe = ForceProbe(args.port, verbose=args.verbose)
    except (RuntimeError, serial.SerialException) as e:
        print("ERROR:", e)
        return 1
    try:
        if args.cmd == "tare":
            print(probe.tare())
        elif args.cmd == "cal":
            print(probe.calibrate(args.grams))
        elif args.cmd == "raw":
            print(probe.raw())
        elif args.cmd == "monitor":
            writer, fh = None, None
            if args.csv:
                fh = open(args.csv, "w", newline="")
                writer = csv.writer(fh)
                writer.writerow(["nano_ms", "force_g"])
            t_end = time.monotonic() + args.seconds if args.seconds > 0 else math.inf
            seq = -1
            try:
                while time.monotonic() < t_end:
                    s = probe.wait_new(seq, 1.0)
                    if s is None:
                        print("no data ...")
                        continue
                    seq = s.seq
                    print(f"{s.millis:>10d} ms  {s.grams:9.2f} g")
                    if writer:
                        writer.writerow([s.millis, s.grams])
            except KeyboardInterrupt:
                pass
            finally:
                if fh:
                    fh.close()
    except RuntimeError as e:
        print("ERROR:", e)
        return 1
    finally:
        probe.close()
    return 0


if __name__ == "__main__":
    sys.exit(main())

    步驟和 A-07 一樣，但主控臂每個關節用的馬達型號不同。程式叫你接哪個關節，就要拿對應型號的那顆。拿錯的話 ID 會寫到錯的馬達上，裝好之後推起來會太重或撐不住。

    設定順序程式提示關節ID拿這種馬達
    第 1 顆gripper夾爪61/147　C046
    第 2 顆wrist_roll手腕旋轉51/147　C046
    第 3 顆wrist_flex手腕俯仰41/147　C046
    第 4 顆elbow_flex手肘31/191　C044
    第 5 顆shoulder_lift肩部抬升21/345　C001
    第 6 顆shoulder_pan肩部旋轉11/191　C044
    先分好再開始

    官方文件沒有說明三種型號外觀怎麼分辨，拆箱時就要分開放、做好標示。主控臂的驅動板要用另一個連接埠，先重做一次 A-06 找出來。

    把 COM4 換成主控臂驅動板的連接埠
    lerobot-setup-motors --teleop.type=so101_leader --teleop.port=COM4
    C-03

    組裝主控臂

    1. 關節 1 到 5：照 A-09 到 A-13 一模一樣的步驟，只是馬達換成上表對應 ID 的那顆。
    2. 握把與扳機：主控臂沒有夾爪，改成下面這四步。
    1. 把主控臂手腕座裝到手腕上，用 4 顆 M3 × 6 鎖住。
    2. 用 1 顆 M2 × 6 把握把裝到手腕座上。
    3. 放入夾爪馬達 ID 6，兩側各用 2 顆 M2 × 6 固定，裝一片舵盤並用 1 顆 M3 × 6 鎖住。
    4. 用 4 顆 M3 × 6 裝上扳機。官方原文寫「follower trigger」，官方主控臂 URDF 模型裡裝在這個位置的是 Trigger_SO101，也就是主控臂的扳機。

    圖由官方 URDF 模型算繪，橘色是新裝的零件。手臂擺的是校準時的中間姿勢，組裝時你手上的零件角度可能不同。

    官方影片：主控臂握把組裝

    1. 串線與固定：照 A-15 串接馬達線、裝上驅動板、用桌夾固定在桌邊。
    C-04

    校準主控臂

    流程和 A-16 一樣：上臂朝上、前臂朝前擺到中間位置按 Enter，除了手腕旋轉之外每個關節轉到兩端，再按 Enter 存檔。

    主控臂的連接埠與名字
    lerobot-calibrate \
    --teleop.type=so101_leader \
    --teleop.port=COM4 \
    --teleop.id=my_awesome_leader_arm

    存檔位置：~/.cache/huggingface/lerobot/calibration/teleoperators/so_leader/my_awesome_leader_arm.json

    C-05

    雙臂遙控

    兩隻手臂都接上電腦後執行，名字要和校準時一樣
    lerobot-teleoperate \
    --robot.type=so101_follower \
    --robot.port=COM3 \
    --robot.id=my_awesome_follower_arm \
    --teleop.type=so101_leader \
    --teleop.port=COM4 \
    --teleop.id=my_awesome_leader_arm
    1. 執行前，先把兩隻手臂擺成差不多的姿勢，避免執行臂一開始就大幅度跳動。
    2. 慢慢推主控臂，確認執行臂跟著動。扣主控臂的扳機，執行臂的夾爪會跟著開合。
    3. 要停止就按 Ctrl + C，程式會斷開兩隻手臂。執行臂會放掉出力，記得先扶好或讓它停在桌面附近。
    名字很重要

    官方說明：LeRobot 用 id 找校準檔。遙控、錄資料、跑 AI 都要用同一組名字，不然它會以為還沒校準，又要求你重新校準。

    Z-01

    看到這些訊息時怎麼辦

    畫面上的訊息原因處理方式
    Could not connect on port '...'連接埠寫錯，或驅動板沒接好重新執行 lerobot-find-port，確認 USB 和電源都插好
    Motor '...' (model 'sts3215') was not found設定 ID 時找不到馬達檢查電源、USB、3-pin 線；Waveshare 跳線要在 B
    ... different than the one expected: '777'設定 ID 時同時接了不只一顆馬達一次只接一顆馬達
    Missing motor IDs組裝後有馬達沒回應多半是串接的 3-pin 線鬆了，或那顆馬達沒設定過 ID
    Some Motors use different firmware versions馬達韌體版本不一致用飛特官方的 Windows 軟體更新韌體，下載頁；更新時絕對不能斷電或拔 USB
    Some motors have the same min and max values校準時有關節沒轉到重新校準，手腕旋轉以外的關節都要轉到兩端
    Mismatch between calibration values ...找不到對應名字的校準檔確認 --robot.id、--teleop.id 和校準時一樣
    Incorrect status packet!匯流排偶爾傳錯資料，多個關節同時動時比較常見程式預設會重試 2 次；常出現時可以加 --robot.num_read_retries=5
    'feetech-servo-sdk' is required but not installed少裝套件在 lerobot 資料夾執行 pip install -e ".[feetech]"
    'pyserial' is required ...少裝套件執行 pip install -e ".[core_scripts]"
    Linux 上 Permission denied沒有連接埠權限sudo chmod 666 /dev/ttyACM0

    還是解決不了，可以到官方 LeRobot Discord 發問。
