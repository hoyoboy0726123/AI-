# LeLab 中文版：中文／EN 一鍵切換

這個資料夾是官方 [huggingface/leLab](https://github.com/huggingface/leLab) 的完整原始碼，加上一個「中文切換外掛」。
畫面右下角（`?` 說明按鈕上方）多了一顆 **中文／EN** 按鈕，按一下就切換語言，下次打開會記得你的選擇。
第一次打開時，瀏覽器是中文就顯示中文，否則顯示英文。

## 安裝（使用者）

需要 `git` 和 `uv`（安裝方法見 SO-101 手冊 L-01）。

```bash
git clone -b claude/project-review-sos0lj --single-branch https://github.com/hoyoboy0726123/AI-.git
uv tool install --force --with-executables-from huggingface_hub ./AI-/lelab-zh
lelab
```

- 這個分支合併到 `main` 之後，第一行可以拿掉 `-b claude/project-review-sos0lj`。`--single-branch` 只下載這個分支，不會把網站的發布紀錄一起抓下來。
- `--force` 會取代已經裝好的官方英文版 LeLab，指令一樣是 `lelab`。
- `--with-executables-from huggingface_hub` 會一起裝好 `hf` 指令，之後才能用 `hf auth login` 登入 Hugging Face。
- 從本機資料夾安裝的 LeLab 不會跳出「有新版本」的自動更新，避免一按更新就被換回只有英文的官方版。

## 更新（使用者）

維護者合併好官方更新後，執行：

```bash
cd AI-
git pull
uv tool install --force --reinstall-package lelab --with-executables-from huggingface_hub ./lelab-zh
```

`--reinstall-package lelab` 會重新建置網頁介面，新的翻譯才會生效。

## 合併官方更新（維護者）

在乾淨的工作目錄執行：

```bash
python lelab-zh/zh-tools/update_from_upstream.py
```

腳本會做這些事：

1. 用 `git subtree pull --squash` 把官方最新的 `main` 合併進 `lelab-zh/`。
2. 中文外掛只新增檔案，再加上 `frontend/src/main.tsx` 第一行的一行 import，所以通常不會有衝突。
   如果官方剛好也改了那幾行，腳本會採用官方版本，再把 import 加回去。
   其他檔案有衝突時，腳本會停下來，請人工處理。
3. 列出這次更新新增、還沒翻譯的英文字串。

把列出的字串加進 `frontend/src/i18n/zh-TW.json` 的 `strings`，然後檢查：

```bash
cd lelab-zh/frontend
npm ci
node scripts/i18n-check.mjs     # 應該顯示 not translated yet: 0
npx vitest run src/i18n         # 外掛的測試
npx vite build                  # 確認可以建置
```

沒翻譯到的字串只會照常顯示英文，不會讓程式壞掉。所以官方更新可以先合併，翻譯之後再補。

## 檔案

| 檔案 | 用途 |
|---|---|
| `frontend/src/i18n/zh-TW.json` | 翻譯表。`strings` 是整句對照，`patterns` 處理含變數的句子（例如 `Create "so101"`），`ignore` 是刻意保留英文的字串 |
| `frontend/src/i18n/translator.ts` | 翻譯引擎：把畫面上的英文換成中文，切回英文時再換回來 |
| `frontend/src/i18n/index.ts` | 啟動翻譯、加上切換按鈕、記住選擇（瀏覽器的 `localStorage`，鍵名 `lelab.lang`） |
| `frontend/src/i18n/i18n.test.tsx` | 測試 |
| `frontend/scripts/i18n-check.mjs` | 從原始碼找出所有介面字串，列出還沒翻譯的 |
| `zh-tools/update_from_upstream.py` | 合併官方更新 |
| `frontend/src/main.tsx` 第一行 | 唯一改到的官方檔案：`import './i18n'` |

## 運作方式

官方程式碼裡的英文字串一個都沒改。外掛在瀏覽器裡監看畫面（`MutationObserver`），
看到整段文字剛好是翻譯表裡的英文，就換成中文；`placeholder`、`title`、`aria-label` 這些屬性也一樣。
React 重新畫面時寫回英文，外掛會再翻一次；切回英文時，會把原文放回去。
使用者輸入的內容、程式碼區塊、加了 `data-no-i18n` 的元素都不會被翻譯。

關節名稱（`shoulder_pan`、`wrist_roll` 等）、手臂和資料集名稱、檔名、模型名稱（ACT、SmolVLA 等）刻意保留英文，和 SO-101 手冊一致。
