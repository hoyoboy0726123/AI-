LeLab：用瀏覽器操作手臂

LeLab 是 Hugging Face 官方的網頁介面，把校準、遙控、錄資料、訓練 AI 都做成按鈕，不用記指令。它要主控臂和執行臂都準備好才能遙控，所以請先完成階段 C，再來用這一章。手冊前面的指令照樣能用，兩邊可以交替使用。

LeLab 可以做還是要用手冊的指令
找連接埠、校準兩隻手臂設定馬達 ID：A-07、C-02
雙臂遙控，畫面上有 3D 手臂即時跟著動只接執行臂、用 Python 控制：A-17
錄資料、逐格看錄好的資料、重播力感測和推按鍵：階段 B
在自己電腦或雲端訓練 AI，訓練好直接讓手臂跑

LeLab 目前只支援 SO-101。本章依 huggingface/leLab 原始碼 commit 1894ab5（2026-11-06，Apache-2.0）和 LeRobot 官方文件的 LeLab 頁查證，按鈕名稱照畫面上的英文原文寫。

L-01

安裝 LeLab

LeLab 自己會帶一套 LeRobot 0.7.0，裝在獨立的地方，不會動到 A-05 建好的 conda 環境。官方用 uv 這個工具安裝。

  1. 安裝 uv。Windows 在 Miniforge Prompt 執行第一行，macOS 和 Linux 在終端機執行第二行。裝完把視窗關掉，重新開一個。
Windows
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
macOS / Linux
curl -LsSf https://astral.sh/uv/install.sh | sh
  1. 安裝 LeLab。這一步要用到 git。Windows 請在 Miniforge Prompt 先執行 conda activate lerobot，A-05 裝的 git 就在這個環境裡。第一次安裝會下載 PyTorch 等大型套件，要等一段時間，硬碟也要留幾 GB。
所有系統
uv tool install git+https://github.com/huggingface/leLab.git
  1. 啟動。以後每次要用，執行 lelab 就好，瀏覽器會自動打開 http://127.0.0.1:8000。用 LeLab 的期間，這個終端機視窗不要關，關掉 LeLab 就停了。
啟動 LeLab
lelab
出現 port 8000 is already in use

上一次的 LeLab 還沒完全關掉。執行 lelab --stop 再重新執行 lelab。

L-02

建立手臂設定

LeLab 把一組主控臂加執行臂叫做一個 robot。先幫我們這一組取個名字。

  1. 先接好電源和 USB。兩隻手臂的電源都接上，USB 都接到這台電腦。電源別插錯：執行臂用它馬達對應的電源，主控臂一律 5V，詳見 A-15。
  2. 取名字。在首頁左上角的手臂選單輸入名字，例如 so101，按 Create "so101"。
  3. 看狀態。名字旁邊會顯示 Needs configuration，表示還沒設定連接埠和校準。
  4. 進入設定。按名字旁邊的齒輪圖示，滑鼠移上去會顯示 Configure (calibrate)，進入 Device Calibration 頁面。
L-03

設定連接埠，校準兩隻手臂

執行臂和主控臂各做一次。先選 Robot (Follower) 做執行臂，再選 Teleoperator (Leader) 做主控臂。

  1. 找連接埠。按找連接埠的按鈕，畫面出現 Unplug the ... arm 時，拔掉那隻手臂的 USB，LeLab 會自動找出連接埠並記住，找到後再把 USB 插回去。原理和 A-06 的 lerobot-find-port 一樣。
  2. 已經用指令校準過：直接選現有的檔案。LeLab 和手冊的指令把校準檔存在同一個資料夾。在 Select an existing calibration file 選執行臂的 my_awesome_follower_arm.json，或主控臂的 my_awesome_leader_arm.json，畫面出現 Calibration linked 就好，不用重新校準。
  3. 還沒校準：先擺姿勢，再按開始。把手臂擺到中間位置，和 A-16 一樣：上臂朝上、前臂朝前。擺好才按 Start Calibration，LeLab 會在按下的那一刻記下中間位置。
  4. 每個關節轉到兩端。和指令版不同，這裡手腕旋轉也要轉。每個關節的範圍夠大，旁邊就會出現勾勾。全部打勾後按 Save Calibration，畫面出現 Calibration completed successfully!。
  5. 換另一隻手臂。選另一個裝置類型，重複上面的步驟。
出現 Motor discontinuity detected

開始校準時手臂不在中間位置。把每個關節擺回中間，再按一次 Start Calibration。

選了現有的檔案，手臂動作卻怪怪的

LeLab 用的 LeRobot 版本比手冊新一版。遇到動作方向不對或位置偏掉，就在 LeLab 裡重新校準一次。

L-04

用 LeLab 雙臂遙控

  1. 先擺姿勢。把兩隻手臂擺成差不多的姿勢，避免執行臂一開始就大幅度跳動。
  2. 開始遙控。首頁按黃色的 Teleoperation 按鈕，畫面出現 Teleoperation Started，並切到 3D 手臂畫面。按鈕是紅色、按不下去，表示還有手臂沒設定好，回 L-03 檢查。
  3. 慢慢推主控臂。執行臂會跟著動，畫面上的 3D 手臂也會即時跟著動。
  4. 停止。按畫面上的返回鍵回首頁，LeLab 就會停止遙控。停下來時執行臂會放掉出力，記得先扶好，或讓它停在桌面附近。
一個連接埠一次只能給一個程式用

用 LeLab 時，先關掉其他正在跑的 lerobot-teleoperate 或 Python 程式。要改回用指令，也要先在 LeLab 停止遙控，或在終端機按 Ctrl + C 關掉 LeLab。

L-05

其他功能：錄資料、訓練、讓 AI 操作

這些功能要讓手臂學會一個動作才會用到。錄資料和訓練通常要接攝影機，本手冊還沒有寫攝影機的安裝，這裡先介紹每個按鈕在哪裡，實際操作請看官方影片。

首頁的位置用途重點
Dataset 選單建立新資料集並開始錄，或打開已經錄好的要填 Dataset Name、Task Description、Number of Episodes。錄的時候按空白鍵或 → 換下一段，按 Delete 或 ← 重錄這一段。官方建議至少錄 30 段。
打開已錄好的資料集逐格看每段的影像和關節動作，可以重播、上傳重播會讓執行臂照錄好的動作再做一次，旁邊不要放東西。
Create a model 的 Training用錄好的資料訓練 AI可以在自己電腦訓練，或用 Hugging Face 的雲端 GPU 訓練。雲端要先執行 hf auth login 登入，而且要付費。
首頁下方的工作清單看訓練進度，選訓練好的模型讓手臂執行讓 AI 操作時，相機的擺放和方向要和錄資料時一樣。

官方影片：LeLab 操作示範

按鍵測試還是用階段 B

LeLab 沒有接力感測器、教點位、設定目標力量這些功能。要讓手臂用固定的力量推按鍵，還是用階段 B 的 force_probe.py。
