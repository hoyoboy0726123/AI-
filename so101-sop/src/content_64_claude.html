延伸

用 Claude Code 協助：從校準到訓練

軟體都裝好之後，可以讓 Claude Code 在接著手臂的筆電上幫忙：下指令、檢查結果、看攝影機照片、算訓練參數、寫測試程式、看懂錯誤訊息。動手的部分（接線、轉關節、示範動作）還是要人來做，會讓手臂動的指令也一定要你同意才執行。

K-01

在筆電上準備 Claude Code

  1. 裝在接手臂的那台筆電。Claude Code 要在連著手臂和攝影機的電腦上跑，才碰得到 USB。可以裝 Claude 桌面 App（內含 Claude Code），或照官方安裝說明裝指令版。需要有 Claude Code 使用權限的 Claude 帳號。
Windows PowerShell（官方安裝指令）
irm https://claude.ai/install.ps1 | iex
  1. 在 AI- 資料夾打開。就是 L-01 用 git clone 下載的那個資料夾。Claude Code 打開時會自動讀 CLAUDE.md，裡面寫好了我們的設備、電源、校準檔名稱、常用指令和安全規則，不用每次重新解釋。
  2. 保持「每次詢問」。Claude Code 要執行指令前會先問你。操作手臂時保持這個預設模式，不要切成自動接受或略過權限。
  3. 人不在電腦前也能用（選用）。在 AI- 資料夾的終端機執行 claude remote-control，就能用手機或平板上的 Claude App 連到這台筆電操作。要用 claude.ai 帳號登入（Pro、Max、Ultra、Team 或 Enterprise 方案，API 金鑰不行）；Team 和 Enterprise 要管理員先在後台開啟。詳見官方說明。
手臂動的時候，人一定要在現場

就算用平板遠端下指令，手臂要動之前也要有人站在旁邊，手放在執行臂的電源旁。

K-02

分工與安全規則

Claude Code 做你做
下不會讓手臂動的指令：檢查 GPU、列出連接埠、找攝影機、啟動 LeLab接線、插拔 USB 和電源
告訴你下一步要做什麼，事後檢查結果對不對需要按 Enter、用手轉關節的步驟（設定 ID、校準）
看攝影機照片，建議角度和光線怎麼調把攝影機鎖好、調位置
規劃錄資料、檢查錄好的資料、算訓練步數、啟動並看著訓練用主控臂示範任務，AI 學的就是你的動作
寫測試程式、分析結果、做報表手臂第一次跑新程式時在旁邊看著，最後判斷結果合不合格
  1. 會動的指令一定先問。遙控、錄資料、重播、讓 AI 操作、按壓測試，還有設定馬達 ID、校準，Claude 都要先說明手臂會怎麼動，得到你同意才執行。這些規則寫在 CLAUDE.md 裡。
  2. 停止條件寫在程式裡。Claude 下指令後看不到手臂的即時動作，沒辦法在幾毫秒內停手。所以按壓這類動作，一定要用有力量上限和行程上限的程式，例如 B-06 的 force_probe.py push。
  3. 要按 Enter 的指令，在你自己的視窗執行。lerobot-setup-motors、lerobot-calibrate、lerobot-find-port 執行到一半，會等你按 Enter。Claude 在背景跑指令時沒辦法替你按，所以它會給你指令，請你在另一個 Miniforge Prompt 視窗執行，做完再請它檢查。也可以直接用 LeLab 的網頁按鈕做。
K-03

從校準到訓練：每一步這樣跟 Claude 說

照順序一步一步來，做完一步確認沒問題，再進下一步。綠色框裡的句子可以直接複製貼給 Claude，也可以用自己的話說。

  1. 檢查環境

    「幫我確認 LeLab 和 GPU 都裝好了」

    Claude
    執行 nvidia-smi，檢查 PyTorch 有沒有用到 GPU，看 lelab 有沒有警告；有問題就照 T-04 修
    你
    看結果，需要重裝時同意它執行
  2. 找連接埠

    「幫我找兩隻手臂的連接埠」

    Claude
    先列出連接埠，請你拔掉一隻手臂的 USB，再列一次，比對出哪個是執行臂、哪個是主控臂。USB 重插後可能會變，每次開工前都重新確認
    你
    照指示拔插 USB
  3. 校準

    「帶我校準執行臂，再校準主控臂」

    Claude
    告訴你中間姿勢怎麼擺，給你校準指令；你做完後檢查校準檔有沒有存好、數值合不合理
    你
    在自己的視窗執行指令，按 Enter，用手轉關節（或在 LeLab 校準頁操作）
  4. 遙控確認

    「我要試遙控，幫我確認可以開始」

    Claude
    檢查電源、連接埠沒被占用、校準檔名稱一致，提醒安全事項
    你
    在 LeLab 首頁按黃色的「遙控」，慢慢推主控臂（L-04）
  5. 攝影機

    「幫我找攝影機，看看畫面拍得清不清楚」

    Claude
    執行 lerobot-find-cameras opencv，打開拍到的照片，告訴你看不看得到手臂、物品和目標，光線夠不夠
    你
    調整攝影機位置，在 LeLab 加入 front、wrist（T-02）
  6. 規劃錄資料

    「我要訓練手臂從桌上拿手把放進治具，幫我規劃怎麼錄」

    Claude
    建議要放幾個位置、每個位置錄幾段、每段幾秒，寫成一張清單
    你
    照清單在 LeLab 示範並錄製（T-03）
  7. 檢查資料

    「幫我檢查剛錄的資料集」

    Claude
    確認片段數量、每段長度、兩支攝影機的影片都在，找出太短或可能錄壞的片段
    你
    需要的話，重錄它挑出來的片段
  8. 訓練

    「幫我用 ACT 訓練這個資料集」

    Claude
    照資料量算訓練步數，告訴你 LeLab 要填什麼（或經你同意直接用指令開始），之後看進度、預估完成時間
    你
    在 LeLab 按「開始訓練」，筆電插電、別讓它睡眠
  9. 讓 AI 操作

    「訓練好了，我要試跑，幫我準備」

    Claude
    建議用哪個檢查點，提醒最長時間先設 20 秒、攝影機要對應好
    你
    站在旁邊、手放電源旁，在 LeLab 按「開始推論」（T-06）
  10. 改進

    「它常常拿不到，幫我看看是什麼原因」

    Claude
    看你拍的照片或影片、比對錄資料時的畫面，建議多錄哪些位置、要不要加訓練步數
    你
    補錄資料、重新訓練
遇到錯誤時

直接把整段錯誤訊息貼給 Claude，或拍下畫面傳給它。也可以先對照附錄 Z-01。

K-04

按鍵測試程式也可以請它寫

你們的按鍵、十字鍵測試，比較適合用程式控制，不需要 AI 訓練。可以請 Claude Code 根據 B-06 的 force_probe.py 寫正式的測試程式，例如：

  • 「幫我寫一個程式：記住十字鍵上、下、左、右四個位置，每個方向用 50 克壓 100 次，記錄每次的峰值力量，存成 CSV。」
  • 「把這次測試的 CSV 做成報表，標出力量異常的那幾次。」
新程式照順序試

先關扭力空跑確認路徑 → 低速、短行程 → 才用正常速度。力量一定要設上限。Claude 每一步都會先問過你。
