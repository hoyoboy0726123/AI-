故障排除與資料來源

錯誤訊息照程式原文列出，方便你直接比對畫面上的文字。

Z-01

看到這些訊息時怎麼辦

畫面上的訊息原因處理方式
Could not connect on port '...'連接埠寫錯，或驅動板沒接好重新執行 lerobot-find-port，確認 USB 和電源都插好
Motor '...' (model 'sts3215') was not found設定 ID 時找不到馬達檢查電源、USB、3-pin 線；Waveshare 跳線要在 B
... different than the one expected: '777'設定 ID 時同時接了不只一顆馬達一次只接一顆馬達
Missing motor IDs組裝後有馬達沒回應多半是串接的 3-pin 線鬆了，或那顆馬達沒設定過 ID
Some Motors use different firmware versions馬達韌體版本不一致用飛特官方的 Windows 軟體更新韌體，下載頁；更新時絕對不能斷電或拔 USB
Some motors have the same min and max values校準時有關節沒轉到重新校準，手腕旋轉以外的關節都要轉到兩端
Mismatch between calibration values ...找不到對應名字的校準檔確認 --robot.id、--teleop.id 和校準時一樣
Incorrect status packet!匯流排偶爾傳錯資料，多個關節同時動時比較常見程式預設會重試 2 次；常出現時可以加 --robot.num_read_retries=5
'feetech-servo-sdk' is required but not installed少裝套件在 lerobot 資料夾執行 pip install -e ".[feetech]"
'pyserial' is required ...少裝套件執行 pip install -e ".[core_scripts]"
Linux 上 Permission denied沒有連接埠權限sudo chmod 666 /dev/ttyACM0

還是解決不了，可以到官方 LeRobot Discord 發問。
