A-05

安裝 LeRobot 軟體

LeRobot 是 Hugging Face 的開源機器人軟體，SO-101 的設定、校準和控制都靠它。官方要求 Python 3.12 以上，建議用 Miniforge 的 conda 管理環境。以下指令照官方安裝文件，查證版本為 LeRobot 0.6.2。

  1. 安裝 Miniforge。Windows 請到 Miniforge 下載頁 下載 Windows 安裝程式，裝好後從開始選單打開「Miniforge Prompt」，後面的指令都在這個視窗輸入。macOS 和 Linux 用官方這兩行：
macOS / Linux 終端機
wget "https://github.com/conda-forge/miniforge/releases/latest/download/Miniforge3-$(uname)-$(uname -m).sh"
bash Miniforge3-$(uname)-$(uname -m).sh
  1. 建立並啟用環境，安裝 ffmpeg。以後每次開新視窗要用 LeRobot，都要先執行 conda activate lerobot。
所有系統
conda create -y -n lerobot python=3.12
conda activate lerobot
conda install ffmpeg -c conda-forge
  1. 下載 LeRobot 原始碼並安裝。SO-101 需要兩組額外套件：core_scripts 提供校準與遙控指令，feetech 是 STS3215 馬達的驅動程式。
所有系統
git clone https://github.com/huggingface/lerobot.git
cd lerobot
pip install -e ".[core_scripts]"
pip install -e ".[feetech]"
沒有 git 的話

Windows 可以先在 Miniforge Prompt 執行 conda install git -c conda-forge，再執行上面的指令。

安裝出錯時

Linux 若出現編譯錯誤，官方建議先裝系統套件：sudo apt-get install cmake build-essential python3-dev pkg-config libavformat-dev libavcodec-dev libavdevice-dev libavutil-dev libswscale-dev libswresample-dev libavfilter-dev。ffmpeg 有問題時，官方建議改裝 7.1.1 版：conda install ffmpeg=7.1.1 -c conda-forge。

檢查安裝結果
pip show lerobot
A-06

接上驅動板，找出連接埠

料件驅動板電源供應器USB-C 線
  1. 設定跳線。如果你的驅動板是 Waveshare，官方說明要把板子上的兩個跳線帽都插在 B 那一側，也就是 USB 模式。
  2. 接電源與 USB。電源供應器插上驅動板，USB-C 線一端接驅動板、一端接電腦。這時候先不要接馬達。
  3. 執行找連接埠的指令。程式會請你拔掉 USB 線再按 Enter，它比較拔線前後的差異，就知道哪一個是驅動板。
啟用 lerobot 環境後執行
lerobot-find-port
你的系統連接埠長相額外步驟
WindowsCOM3、COM4 這類名稱不需要
macOS/dev/tty.usbmodem585A0076841 這類名稱不需要
Linux/dev/ttyACM0、/dev/ttyACM1官方建議執行 sudo chmod 666 /dev/ttyACM0 給予權限
找不到連接埠時

先換一條 USB-C 線試試。只能充電、不能傳資料的線，電腦不會偵測到驅動板。這是一般經驗，官方文件沒有特別寫。

A-07

設定 6 顆馬達的 ID

新馬達出廠時 ID 通常都是 1。同一條線上的馬達 ID 必須不同，電腦才分得出誰是誰。這個步驟一次只接一顆馬達，程式會自動寫入 ID 和通訊速率 1,000,000，寫進馬達的記憶體後就不用再做。

把 COM3 換成你在 A-06 抄下的連接埠
lerobot-setup-motors --robot.type=so101_follower --robot.port=COM3
  1. 程式會先顯示 Connect the controller board to the 'gripper' motor only and press enter.：拿一顆馬達，用 3-pin 線接到驅動板，只接這一顆，按 Enter。
  2. 畫面出現 'gripper' motor id set to 6。拿膠帶在這顆馬達上寫「6 夾爪」。
  3. 把 3-pin 線從驅動板那一端拔掉，馬達那一端可以留著，之後組裝剛好用得到。換下一顆馬達，用另一條 3-pin 線接到驅動板。
  4. 照提示依序完成：手腕旋轉 5、手腕俯仰 4、手肘 3、肩部抬升 2、肩部旋轉 1。
設定順序程式裡的名稱關節寫入的 ID
第 1 顆gripper夾爪6
第 2 顆wrist_roll手腕旋轉5
第 3 顆wrist_flex手腕俯仰4
第 4 顆elbow_flex手肘3
第 5 顆shoulder_lift肩部抬升2
第 6 顆shoulder_pan肩部旋轉1
官方提醒

每次按 Enter 前都先檢查接線。換馬達時手會碰到驅動板，電源線很容易被扯鬆。官方的設定示範影片在 這裡。

出現錯誤時

看到 Motor 'xxx' (model 'sts3215') was not found，代表電腦找不到馬達：檢查電源、USB 線、3-pin 線，以及 Waveshare 跳線是否在 B。看到 different than the one expected: '777'，代表同時接了不只一顆馬達，或接到不是 STS3215 的馬達。
